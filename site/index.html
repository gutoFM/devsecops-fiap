Esteira DevSecOps

Todo push passa por três barreiras antes de virar entrega. Se uma delas acusar, o commit fica vermelho.

01

Gitleaks

Varre o histórico de commits atrás de senhas, tokens e chaves. Segredo commitado não some apagando o arquivo, então a barreira precisa estar antes do merge.

02

Semgrep

Lê o código como estrutura e aponta padrões perigosos, como eval com entrada do usuário, SQL concatenado e shell=True.

03

Trivy

Constrói a imagem Docker deste site e procura vulnerabilidades conhecidas nos pacotes do sistema e nas dependências antes de a imagem virar artefato.

Como rodar

docker build -t devsecops-fiap .
docker run --rm -p 8080:8080 devsecops-fiap

O container usa nginx sem root e responde em http://localhost:8080.
